# Environment Files

This directory documents the Python dependencies used by the original project environments.

## PointPillars

`pointpillars/requirements.txt` records the legacy Python/CUDA dependency versions used for the PointPillars environment.

## AB3DMOT

`ab3dmot/requirements.txt` records the legacy Python dependencies used for the AB3DMOT environment.

## ROS 2

ROS 2 package metadata and dependencies are kept with the ROS 2 package itself under:

`ros2/lidar_tracking_demo/`

## Important note

These requirement files reproduce the original project environment and contain older package versions. They are provided for documentation and reproducibility rather than as a recommendation for a modern Python environment. Compatibility may depend on the Python, CUDA, and operating-system versions used during the project.
