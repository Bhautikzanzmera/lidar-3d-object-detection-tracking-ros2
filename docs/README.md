# Project Documentation

This directory contains the technical documentation for the LiDAR 3D Object Detection and Multi-Object Tracking project.

## Technical Portfolio Report

The report documents:

- PointPillars-based LiDAR 3D object detection
- KITTI dataset preparation and evaluation
- Detection-to-tracking format conversion
- AB3DMOT multi-object tracking integration
- ROS 2 and RViz2 visualization
- DAIR-V2X-I cross-dataset experimentation
- Reproducibility, debugging and evaluation limitations
